# Assumptions log

Choices made while building Kairo without asking the project owner first.
Each one says why it was made and how to undo it, so any of them can be
questioned later. This covers how Kairo is built. It does not cover design
data: Kairo never assumes a missing tolerance, curve or datasheet value.
